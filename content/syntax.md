# A07｜Rust 語法與符號字典

使用法：每看到不懂的符號先找這裡，再回對應章節研究完整因果。這是索引，不取代章節的完整推導。

## 一、值、變數與作用域

let：建立變數綁定，不是物件複製指令。

mut：允許變更綁定或取得特定可變借用。

const：帶型別的編譯期常數。

static：具有固定存放位置的項目；共享可變 static 需要額外安全處理。

fn：定義函式；main：可執行程式入口。

{}：作用域與區塊，區塊也能產生值。

;：將運算式結果丟棄並形成語句的常見標記；不是每行都必須加。

->：函式回傳型別。

()：無資料的單位型別，亦表示空參數列表。

_：忽略或讓編譯器推導的佔位符，細節依語法位置。

## 二、資料型別

i8/i16/i32/i64/i128/isize：有號整數；u 系列：無號整數。

f32/f64：二進位浮點，不是完全精確的十進位數。

bool：真假；char：Unicode scalar，不必然是完整可見字素。

str：動態大小的 UTF-8 字串切片目標型別，通常以 &str 使用。

String：擁有 UTF-8 位元組緩衝區的可成長字串。

[T; N]：固定長度陣列；[T]：動態大小切片型別，通常以 &[T] 使用。

Vec<T>：擁有可成長序列的集合。

Option<T>：Some(T) 或 None，表示有無值。

Result<T,E>：Ok(T) 或 Err(E)，表示成功或帶原因的失敗。

struct：具欄位的自訂型別；enum：多種互斥形態之一。

impl：為型別實作方法或 trait。

## 三、所有權、借用與指標

&value：建立共享借用；&mut value：建立獨占可變借用。

*reference：解參考；也會出現在乘法等其他語法中，需看上下文。

move：要求閉包以值捕獲環境（具體仍受捕獲分析影響）。

clone()：顯式複製，由 Clone trait 決定如何複製。

Copy：允許位元複製語義的標記 trait；有 Drop 的型別不能是 Copy。

Drop：離開生命週期時清理資源的 trait。

Box<T>：擁有 T 的間接配置；Rc<T>：單執行緒共享擁有權；Arc<T>：執行緒安全參考計數。

RefCell<T>：執行時借用檢查；Mutex<T>：互斥保護共享狀態；Weak<T>：不維持強參考計數的弱引用。

'a：生命週期參數標記，表達引用間的有效性約束，不是倒數計時器。

'static：特殊的靜態生命週期要求，不是所有參考問題的修補膠帶。

## 四、控制流程與模式

if / else：條件分支，條件必須是 bool。

match：依模式分類並取值；需要處理完整的可能性。

loop：無條件重複；while：依條件重複；for：走訪可迭代來源。

break：離開迴圈，可在特定 loop 情境帶回值；continue：進入下一輪。

return：提前返回函式。

if let：只針對特定匹配情形執行。

let ... else：不匹配時必須離開所在流程。

..：不包含右端點的範圍或省略剩餘欄位（視上下文）。

..=：包含右端點的範圍。

|：模式的多個候選，也用於閉包參數界定。

@：模式匹配時同時綁定整體匹配值。

## 五、型別抽象

<T>：泛型參數或型別引數。

T: Trait：型別 T 必須符合指定的能力契約。

where：把泛型約束移到獨立子句。

Self：在 trait / impl 內代表目前實作的型別；self：方法接收者。

dyn Trait：透過 trait object 動態分派的行為介面。

impl Trait：依所在語法位置代表受 trait 約束的型別，與 dyn 語義不同。

type：型別別名或關聯型別宣告。

::：路徑分隔符，亦用於關聯函式與變體。

use：引入路徑名稱；pub：公開項目；mod：定義模組。

crate / super / self：路徑的根、父層、目前位置（依語法位置）。

## 六、巨集、錯誤與編譯條件

println! / vec! / format!：巨集呼叫，! 不是普通函式語法。

#[derive(...)]：讓編譯器或巨集生成 trait 實作。

#[cfg(...)]：條件編譯。

#[test]：標記測試函式。

?：在 Result/Option 等支援情境傳播失敗或缺值；並非忽略錯誤。

unwrap()：取出有效值，失敗通常 panic。

expect(msg)：失敗時 panic 並附上訊息。

panic!：觸發 panic；與一般 Result Err 不相同。

unsafe：明確標出需要程式設計者維護額外安全條件的操作。

## 七、工具指令

rustc：編譯器；rustup：工具鏈管理器；cargo：建構與依賴管理器。

cargo new：建立專案；cargo run：建構並執行；cargo check：快速編譯語意檢查。

cargo fmt：格式化；cargo clippy：程式碼慣例與問題檢查；cargo test：執行測試。

cargo build --release：產生 release 組態；cargo doc：產生 API 文件。

## 八、每次遇到陌生語法的四問

1. 這是值、型別、路徑、借用、控制流程還是巨集？

2. 它從哪裡拿資料？是否拿走所有權？

3. 它回傳什麼型別？可能失敗嗎？

4. 編譯器為何需要這個限制，若不限制會產生什麼錯誤？

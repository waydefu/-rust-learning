## 零基礎閱讀與教學方塊

21 個主課程各增加五種依章節撰寫的教學方塊（共 105 個）：來龍去脈、生活比喻、程式拆解、常見陷阱、動手驗收。原有程式碼區塊及章節標題保留。附錄 A01–A08 此輪不改寫。

編輯方法使用一般 CommonMark 引用：第一段只放粗體標籤（例如 `> **來龍去脈**`），再放一行 `>`，接著用 `> 內容` 撰寫說明。五個固定標籤由建置器辨認，其他引用仍照原樣渲染。HTML 保持停用，不需額外 JavaScript 或依賴。新方塊適配既有淺色與深色主題；驗證器檢查每章五種方塊及文字標籤，瀏覽器測試涵蓋 320px、兩種主題與關閉 JavaScript 時的閱讀。

## 如何驗收變更

`npm run check` 驗證所有 Markdown 來源、頁面與錨點。在每一份 Markdown 中，Rust 程式碼區塊必須標示驗證方式。**run** 編譯且執行。**program** 驗證完整 main。**fragment** 在檢查時補上 main。**continuation** 和前一 Rust 區塊合併。**error E0382** 驗證預期的診斷碼。**test** 執行 Rust 測試。**project name:src/file.rs** 抽到暫存 Cargo 專案驗證。可在檢查輸出定位錯誤的教材與行號。

編譯與測試只涵蓋有標註的 Rust 程式區塊。內文行內語法、Shell 指令與作業系統安裝步驟供閱讀與實作，驗證以實際執行環境為準。網站測驗結果由讀者自我驗收，完成標記可自行切換。
